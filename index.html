About ParkEase System

A modern web-based smart car parking slot booking system developed for college web technology micro projects.

Real-Time Slot Tracking

Tracks parking slot status dynamically using vanilla JavaScript, updating counters instantly as slots are booked or freed.

Automated Rate Billing

Features an automated tariff calculator configured at ₹30 per hour with live summary breakdown and receipt generation.

Fully Responsive

Designed with Tailwind CSS for mobile phones, tablets, and desktop displays with smooth page transitions.

Web Technology Micro Project

Built using HTML5, CSS3 (Tailwind CSS framework), and JavaScript.
